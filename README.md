### 🎯 O que torna o RenanOS especial?
- **Gerenciador de Janelas Nativo no Browser**: Sistema completo de janelas flutuantes com z-index inteligente, minimizar/maximizar, snap nas bordas e performance a 60 FPS.
- **Terminal CLI Funcional**: Interpretador de comandos integrado estilo bash/zsh com animação estilo *Matrix Rain*, comandos de ajuda, diagnóstico de sistema e easter eggs interativos.
- **Ecossistema de Jogos & Áudio**: Minigames interativos que testam agilidade e raciocínio, integrados a sintetizadores de áudio gerados via Web Audio API.
- **Arquitetura 100% Tipada**: Construído com rigor de tipagem estrita em TypeScript, modularização e componentização limpa em React 19.
